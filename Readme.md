# ZeeMailer - AI-Assisted Email Marketing Tool

ZeeMailer is an intelligent, high-converting cold outreach and follow-up email tool. It leverages the Google Gemini AI API to automatically draft personalized emails based on your target niche and seamlessly sends them out using your preferred SMTP server.

## Installation Instructions

ZeeMailer is designed to be easily installable on both Linux and Windows. Make sure you have [Node.js](https://nodejs.org/) installed before proceeding.

### 🐧 For Linux Users

1. Open your terminal.
2. Navigate to the folder containing these files:
   ```bash
   cd /path/to/zeemailer
   ```
3. Make the installer executable:
   ```bash
   chmod +x install.sh
   ```
4. Run the installer:
   ```bash
   ./install.sh
   ```
5. **Usage:** You can now launch the app by double-clicking the **ZeeMailer** icon on your Desktop, or by typing `zeemailer` in any terminal!

### 🪟 For Windows Users

1. Open the `zeemailer` folder.
2. Double-click on `install.bat` to run the installer.
3. If prompted by Windows Defender, click "More info" -> "Run anyway".
4. The script will automatically install dependencies and configure your system.
5. **Usage:** You can now launch the app by double-clicking the **ZeeMailer** icon on your Desktop, or by opening Command Prompt and typing `zeemailer`!
